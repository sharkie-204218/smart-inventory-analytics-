# smart-inventory-analytics for my job interview
Inventory and Supply Chain Analytics Dashboard built with AI-assisted coding for my job applications lol

An interactive inventory and supply chain analytics dashboard built with Python and Streamlit.

## Project Overview

This project demonstrates how inventory data can be transformed into actionable business insights through interactive visualization and automated stock monitoring.

## Current Features

- Inventory quantity and value tracking
- Product category distribution
- Low-stock alerts
- CSV and Excel data upload
- Interactive inventory visualization
- Downloadable inventory reports

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## Business Applications

- Inventory monitoring
- Supply chain visibility
- Stock replenishment planning
- Data-driven operational decision-making

## Data

All sample data is simulated for demonstration purposes.

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
streamlit run app.py
```
